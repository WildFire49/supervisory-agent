# DPD Classification (SMA/NPA Buckets):
- SMA0 → dpd_days BETWEEN 0 AND 31
- SMA1 → dpd_days BETWEEN 30 AND 60
- SMA2 → dpd_days BETWEEN 61 AND 90
- NPA  → dpd_days > 90

# Repayment Logic for DPD Reset:
- Pays only current EMI → Stays in same DPD bucket.
- Pays current + 1 overdue EMI → Moves to lesser DPD bucket.
- Pays all overdue EMIs + current EMI → Considered Regular (dpd_days = 0)

- Compare `emi_amount` vs `emi_collected` to reset DPD if fully paid.

# Prompt Interpretation Rules:
- For any prompt involving **month-wise** or **monthly** calculations (e.g., monthly target, monthly collections, monthly pending):
- When comparing current month vs last month data:
  - Always filter current month using:
    `collection_due_date >= DATE_TRUNC('month', CURRENT_DATE)`
    AND `EXTRACT(DAY FROM collection_due_date) <= EXTRACT(DAY FROM CURRENT_DATE)`

  - Filter previous month using:
    `collection_due_date >= DATE_TRUNC('month', CURRENT_DATE - INTERVAL '1 month')`
    AND `collection_due_date < DATE_TRUNC('month', CURRENT_DATE)`
    AND `EXTRACT(DAY FROM collection_due_date) <= EXTRACT(DAY FROM CURRENT_DATE)`

- Always alias `DATE_TRUNC('month', collection_due_date)` as `collection_month` to avoid ambiguity.

- NEVER reference ambiguous column names like `collection_due_date` in final SELECT or JOIN unless they are properly aliased.

- When grouping by month, use:
    `GROUP BY DATE_TRUNC('month', collection_due_date)` or `GROUP BY 1`
  and **do not use raw `collection_due_date`** in SELECT or JOIN unless it’s filtered properly.

# Business Logic:
- Represents the EMI schedule for each loan (monthly installments).
- total_amount_to_collect = emi_amount + arrear_amount
- Tracks dues that are expected, not actual payments.
- remaining_amount_to_collect = (emi_amount + arrear_amount) - emi_collected
- A prospect is considered **visited** if:
    - `last_repayment_date >= CURRENT_DATE`

# Notes:
- This table does NOT include FO/BM or region information.
- Use 'staging_dashboard.collection_details' to access FO/BM data by joining:
    - `loan_emi_mapping.loan_details_id = collection_details.source_id`

# Join Tips:
- `source_id` joins with:
    - `loan_emi_mapping.loan_details_id`
    - `scheduled.lemid` (indirectly)

# Usage:

- Combine with transactions table for actual collected amounts.

## DISBURSEMENT QUERIES - PREFERRED TABLES
# For ANY query related to loan disbursement, loan amounts, disbursement dates, or disbursement analysis:
# ALWAYS use these tables in order of preference:
# 1. fed_disbursement_details (PRIMARY - most complete data)
# 2. disbursement_details (SECONDARY - fallback option)
# NEVER use collection_details, loan_emi_mapping, or transactions for disbursement data!

## DISBURSEMENT BUSINESS RULES:
# - Use `disbursement_date` for filtering disbursement periods (NOT collection_due_date)
# - Use `loan_amount` for disbursement amounts (NOT emi_amount or amount_paid)
# - Use `disbursement_status = 'success'` to filter successful disbursements
# - Join with collection_user via field_officer_id or branch_manager_id for FO/BM details
# - Join with employee via collection_user for employee names and details

## EXAMPLE CORRECT DISBURSEMENT QUERIES:

# Monthly Disbursement Summary:
SELECT 
    SUM(fd.loan_amount) AS total_disbursed,
    COUNT(*) AS total_loans,
    AVG(fd.loan_amount) AS avg_loan_amount
FROM staging_dashboard.fed_disbursement_details fd
WHERE fd.disbursement_date >= DATE_TRUNC('month', CURRENT_DATE)
  AND fd.disbursement_date < DATE_TRUNC('month', CURRENT_DATE) + INTERVAL '1 month'
  AND fd.disbursement_status = 'success';

# Field Officer Disbursement Performance:
SELECT 
    e.employee_name AS field_officer,
    SUM(fd.loan_amount) AS total_disbursed,
    COUNT(*) AS loans_disbursed
FROM staging_dashboard.fed_disbursement_details fd
JOIN staging_dashboard.collection_user cu ON cu.source_id = fd.field_officer_id
JOIN staging_dashboard.employee e ON e.source_id = cu.employee_id
WHERE fd.disbursement_date >= DATE_TRUNC('month', CURRENT_DATE)
  AND fd.disbursement_date < DATE_TRUNC('month', CURRENT_DATE) + INTERVAL '1 month'
  AND fd.disbursement_status = 'success'
GROUP BY e.employee_name
ORDER BY total_disbursed DESC;
